# تعمیرات لرستان موبایل افشار

نسخه استاتیک فارسی و راست‌چین وب‌سایت با HTML، CSS و JavaScript خام.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا پوشه را روی یک هاست استاتیک قرار دهید.

## ساختار
- ۱۱ صفحه HTML
- ۷ فایل CSS در `styles/`
- منطق تعاملات در `js/app.js`
- نشان اختصاصی SVG در `assets/afshar-mark.svg`

## امکانات نسخه چهارم
- بازطراحی تجربه موبایل با فاصله‌گذاری و چیدمان اختصاصی، هیروی تعمیرگاهی، کارت‌های خدمات و ناوبری پایین صفحه
- راهنمای پیدا کردن مدل با پنجره پایین‌شونده واقعی، بستن با ضربدر/پس‌زمینه/Escape و محتوای متناسب با موبایل، تبلت و ساعت هوشمند
- مدیریت فوکوس و جلوگیری از اسکرول پس‌زمینه هنگام باز بودن راهنما

## امکانات
- هدر ثابت و ناوبری موبایل چهارگزینه‌ای؛ بدون منوی «بیشتر»
- پوسته روشن و تیره با ذخیره انتخاب کاربر
- صفحه فرود با تصویرسازی اختصاصی برد و ابزار تعمیر و انیمیشن‌های کوتاه
- ثبت درخواست در چهار مرحله
- دو روش تحویل: حضوری یا هماهنگی ارسال با پیک پس از ثبت درخواست
- ذخیره درخواست و پیش‌نویس در حافظه محلی مرورگر و پیگیری با شناسه محلی
- پنجره راهنما با بستن از دکمه، پس‌زمینه یا کلید Escape

## محدودیت اتصال
ثبت سفارش و پیگیری این نسخه در همان مرورگر و با `localStorage` انجام می‌شود. برای ثبت مرکزی، ارسال پیامک، هماهنگی واقعی پیک و مشاهده وضعیت تعمیرگاه باید API و Backend متصل شود. هیچ پیام موفقیت شبکه‌ای یا وضعیت ساختگی از تعمیرگاه نمایش داده نمی‌شود.

## فونت و درخواست خارجی
تنها وابستگی خارجی، فونت Estedad از Google Fonts است؛ در صورت عدم دسترسی، فونت‌های جایگزین سیستم استفاده می‌شوند.
